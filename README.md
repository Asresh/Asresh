```text
1. Frame    →  Who is the user, and what's the smallest thing that creates real value?
2. Decide   →  Choose the architecture, scope, and trade-offs — and own them.
3. Build    →  Ship the full stack: frontend, backend, data, and AI where it earns its place.
4. Launch   →  Put a working version in front of users, measure, and iterate.
```

I lead each build the way I'd lead a team: **a clear problem, decisive scope, end-to-end ownership, and something shipped** — whether it's testing a startup idea, streamlining an internal workflow, or exploring an AI feature.

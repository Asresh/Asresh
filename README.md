## 🔁 How I work — idea → MVP

```text
1. Clarify   →  Who's the user? What's the smallest valuable feature?
2. Design    →  An intuitive flow that makes the product obvious.
3. Build     →  Frontend, backend, data, and AI where it adds real value.
4. Launch    →  Put a working version in front of users and iterate.
```

I aim for the **smallest product that delivers a useful result** — whether you're testing a startup idea, streamlining an internal workflow, or exploring an AI feature.
